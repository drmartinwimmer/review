# Milestone 6: Release Pipeline & Automated SemVer Verification

**Milestone Goal:** Configure Release Please (`release-please-config.json`, `.release-please-manifest.json`, `.github/workflows/release.yml`) across all workspace crates (`code-review`, `code-review-check`, `code-review-configure-lints`, `code-review-coverage`) with `flake.nix` synchronization and pre-1.0 (`0.x`) SemVer semantics, and integrate `cargo-semver-checks` into `.github/workflows/ci.yml` to verify both Feature PRs against `origin/main` and Release Candidate PRs against published baselines.

## Detailed Acceptance Criteria

1. `docs/release_pipeline.spec.md` documents the Intent vs. Reality SemVer pipeline, `0.x` bump mappings, topological publish order, and CI gating rules.
2. All four workspace crates (`code-review-configure-lints`, `code-review-coverage`, `code-review-check`, `code-review`) have publish-ready `Cargo.toml` metadata and `README.md` files, and are tracked in `release-please-config.json` and `.release-please-manifest.json`.
3. `flake.nix` version is synchronized with `crates/code-review` via `# x-release-please-version`.
4. `.github/workflows/release.yml` synchronizes workspace lockfiles/manifests on Release PRs and publishes crates in topological dependency order.
5. `.github/workflows/ci.yml` runs `cargo-semver-checks` on both Feature PRs (against `origin/main`) and Release Candidate PRs (against `crates.io` / release tag baselines).
6. Workspace passes `cargo test --all-targets --all-features`, `cargo run -p code-review -- check`, `cargo run -p code-review -- api check`, and `nix flake check && nix build`.
