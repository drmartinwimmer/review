# Milestone 4: API Manifest Engine & Auditor (`code-review api`)

**Milestone Goal:** Integrate the standalone `api-manifest` crate into `code-review` (`code-review api dump` and `code-review api check`) and `code-review-check` (`ApiRunner` / `--api`) to inspect public API surfaces across libraries, binary CLIs, HTTP services, and configuration schemas, and detect uncommitted manifest drift against checked-in `API.md` files.

---

## Task Checklist

- [x] **M4-T0: Update Specifications (`crates/check/SPEC.md`, `plan/M4.md`, `plan/FEEDBACK_M4.md`)**
  - Document `ApiRunner` integration and diagnostic rule mappings in `crates/check/SPEC.md`.
  - Create `plan/M4.md` task checklist and `plan/FEEDBACK_M4.md` feedback template.
  - Update `PLAN.md` and `README.md` to reflect `api-manifest` integration.

- [x] **M4-T1: External `api-manifest` Crate Dependency (`Cargo.toml`)**
  - Remove the in-tree `crates/api` stub crate following the extraction of `api-manifest` into its dedicated repository and publication on crates.io.
  - Add `api-manifest = "0.2.1"` to `[workspace.dependencies]` in `Cargo.toml`.

- [x] **M4-T2: CLI & Check Aggregator Integration (`crates/code-review`, `crates/check`)**
  - Wire `api_manifest::{ApiManifestCommand, ApiManifestError}` into `crates/code-review/src/lib.rs` under `code-review api` (with alias `api-manifest`), returning exit code `1` on `ApiManifestError::DriftDetected`.
  - Implement `ApiRunner` in `crates/check/src/tools/api.rs` using `api_manifest::ApiManifest`.
  - Wire `ApiRunner` and the `--api` flag into `CheckCommand` in `crates/check/src/command.rs`.
  - Add unit tests for `ApiRunner` and CLI subcommand dispatch using `googletest`.

---

## Detailed Acceptance Criteria

1. `crates/api` stub is removed and `api-manifest = "0.2.1"` is configured in `[workspace.dependencies]`.
2. `code-review api` (and `code-review api-manifest`) delegates to `api_manifest::ApiManifestCommand` (`dump` and `check`).
3. `ApiRunner` discovers `API.md` manifests across a workspace or crate and emits `api::drift::breaking` (`Severity::Error`) or `api::drift::addition` (`Severity::Warning`) diagnostics when drift is detected.
4. Workspace passes `cargo test --all-targets --all-features`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo fmt --check`, and `cargo run -p code-review -- purist --path .`.
