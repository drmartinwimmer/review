# Milestone 5: Code Coverage Engine (`code-review coverage`) & CI Integration

**Milestone Goal:** Implement `code-review coverage` wrapping `cargo-llvm-cov` to measure source-based code coverage across line, function, branch, and region dimensions, enforce minimum coverage thresholds (`--fail-under <pct>`), support console/JSON/LCOV output formats, and add a dedicated coverage job to the GitHub Actions CI workflow.

---

## Task Checklist

- [x] **M5-T0: Update Specifications (`crates/coverage/SPEC.md`, `plan/M5.md`, `plan/FEEDBACK_M5.md`)**
  - Define coverage metrics, reporting formats (`console`, `json`, `lcov`), and `--fail-under` threshold enforcement rules.
  - Create `plan/M5.md` task checklist and `plan/FEEDBACK_M5.md` feedback template.

- [x] **M5-T1: LLVM Coverage Subprocess Driver & Parser (`crates/coverage/`)**
  - Implement `LlvmCovRunner` in `crates/coverage/src/tools/llvm_cov.rs` invoking `cargo llvm-cov --all-targets --all-features --json`.
  - Implement `parse_llvm_cov_json`, `CoverageReport`, `CoverageSummary`, `FileCoverage`, and `MetricSummary` in `crates/coverage/src/parser.rs`.
  - Implement `--fail-under <pct>` (alias `--threshold`), `--json`, and `--lcov <path>` in `CoverageCommand` (`crates/coverage/src/command.rs`).
  - Wire `CoverageError::ThresholdNotMet` into `code-review` CLI with exit code `1`.
  - Update checked-in `API.md` manifests (`crates/coverage/API.md`, `crates/code-review/API.md`).

- [x] **M5-T2: CI Workflow Coverage Job (`.github/workflows/ci.yml`)**
  - Add `coverage` job to `.github/workflows/ci.yml` installing `llvm-tools-preview`, `cargo-llvm-cov`, and `jj-cli`, and executing `cargo run -p code-review -- coverage --lcov lcov.info`.
  - Update `PLAN.md` and `README.md` to reflect Milestone 5 completion.

---

## Detailed Acceptance Criteria

1. `crates/coverage/SPEC.md` documents the CLI options, JSON parsing schema, and exit code invariants.
2. `LlvmCovRunner` is isolated in `crates/coverage/src/tools/llvm_cov.rs` in compliance with `purist::centralized_command_execution`.
3. `CoverageCommand::evaluate_report` formats console tables, JSON, and LCOV output and returns `CoverageError::ThresholdNotMet` when line coverage drops below `--fail-under`.
4. `.github/workflows/ci.yml` includes the `coverage` job.
5. Workspace passes `cargo test --all-targets --all-features`, `cargo run -p code-review -- check`, `cargo run -p code-review -- api check`, and `nix flake check && nix build`.
